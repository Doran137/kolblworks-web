# kolblworks.cz

Zdroj webu https://kolblworks.cz (Webhosting Start u Webglobe, doména kolblworks.cz).
Nasazení: soubory nahrát 1:1 do `public_html` přes Webglobe admin → Hosting → Správa souborů
(nebo FTP `ftp.kolblworks.cz`). Certifikát: Let's Encrypt zdarma v admin → SSL certifikát.

- `/index.html` – rozcestník
- `/pdfskener/privacy.html` – zásady ochrany soukromí, aplikace PDF Skener
- `/editor-prostor/privacy-policy.html` – zásady ochrany soukromí, Editor vnitřních a vnějších prostor
